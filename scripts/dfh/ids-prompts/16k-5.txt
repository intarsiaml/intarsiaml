Built on 2026-10-21 from: the 10 ADRs, every `docs/results/*.md`, `docs/research/*`, `docs/proposals/*`, `docs/plans/*`, `docs/backends/hip.md`, the policy parts of the top-level docs, the project memory notes, and unanimis records (origin project intarsiaml). All times are EDT.

Rows were extracted by sub-agents, one lane per source set, and then de-duplicated; they were not individually re-verified. A spot check of the 14 ADR-0005 rows against the ADR found no errors. Weaker sources: ADR-0002 and `docs/quant-moe.md` / `docs/qualify-report-template.md` (their reads partly failed, rows taken from excerpts), four results docs whose reads were garbled (`2026-10-16-metal-weight-residency.md`, `2026-10-18-cuda-moe-w4a16.md`, `2026-10-18-metal-sameslot-main.md`, `2026-10-17-metal-cb-m3-verify-go.md`), and the line numbers in rows from `docs/results/2026-10-19-*.md`, which are approximate. Before relying on a row, open its evidence.

How to read the table:

- **Who** is `user` (the user decided; usually timestamped), `ADR-NNNN`, `agent (<lane>)`, or `open`. `open then resolved/superseded` marks a decision that a source doc left to the user and that was later settled; the status cell says how.
- **Evidence** cells use `mem:<name>` for a project memory note (`~/.claude/projects/-opt-code-intarsiaml/memory/<name>.md`, local to the user's machine) and `unanimis <id>` for a unanimis record. Line numbers in older rows are approximate.
- Where two records disagree, see [Contradictions between records](#contradictions-between-records) and the source docs.
