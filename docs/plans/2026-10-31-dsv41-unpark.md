## Weights and memory budget

Develop on the Mia 2.9 bpw checkpoint: it is the reference engine's own weights, so goldens compare like with like.
Per rank: 98.9 GiB weights. Mia/TensorFold leaves 4.6 GiB free with a 12.2 GiB engine reserve, which is only possible
with earlyoom lowered to `-m 3,2`. Target for intarsiaml: engine non-weight memory at most 6 GiB per rank, so about
10 GiB stays free. If that target fails at Phase 3, fall back to `sudoingx` 2.7 bpw (on NFS) or the vcruz 1.62 bpw pack,
or the user keeps earlyoom lowered for this model (their decision).

Without speculative decode the scope doc's bound is 42-46 tok/s decode, so "tuned" needs Phase 4's TP=2 spec decode.

## Rules for the lanes

- Lane 1a lands first. Ops are appended to the `Op` enum only by 1a, so later lanes fill in a frozen interface.
- Per-op and few-layer CUDA work runs on one Spark next to vLLM (about 80 GB free, `MAX_JOBS=4`). Full TP=2 loads take
  down flight, guidance, capcom and retro: batched into `fleetq reserve` windows.
- Ported code keeps Apache-2.0 notices (TensorFold, BertholomusAI's DSv4.1 family, patch authors) in `LICENSES/` and file headers.
- Sonnet for implementation; Opus for sparse attention, Sinkhorn/hc and the Engram IO tier; 2-3 lanes at a time (quota).
