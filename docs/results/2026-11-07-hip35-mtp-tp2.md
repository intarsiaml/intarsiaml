## What is read, and the plan

Lane mt2 (`2026-11-07-mtp-moe-tp.md`, PR #331) put the MoE MTP head whole on rank 0 under tp > 1: `Model::load_shard` sets
`mtp_whole = opts.mtp && tp.world > 1 && dims.moe.is_some()` and loads the head only on rank 0, against the global dims. That is the
**shared load path**, so it covers the in-process rank path (`--tp 2 --devices 0,1`) as well as the remote-rank path the Sparks use; the
CPU tests of mt2 drive both (`moe_mtp_tp2_greedy_ids_equal_spec_off`: in-process and remote rank). The loader refusals that remain are
`mtp::load_head` (a sharded MoE head without `whole_rows`: unreachable now) and `mtp_head_usable` (recipe defaults only: no default can turn
this on at tp > 1 for an MoE). Nothing in `load.rs` / `mtp.rs` refuses `--spec mtp` with an MoE model at `--tp 2` on in-process HIP ranks.
mt2 left HIP as "untested on the GPU". So the decision on code is **empirical**: this lane builds origin/main (`9b66a25c7`) unchanged
on tatooine and runs the gates; code is written only if the HIP run fails (plan resolution for the head's full-width MoE on rank 0, a kernel
the head needs that HIP does not register, or an ids mismatch). If no code changes, the binary is main's, so the "no-op vs main" gates (HIP plan
show diffs, Metal on endor, CUDA on spark1) are the identity and are not run; the lane's evidence is the HIP plan shows, ids and speed.

## Decision

- No code, no default change. `--spec mtp --tp 2 --devices 0,1` works on HIP for the 35B and is exact (rule (a)); it is a small, reliable speed-up (about +6 to +9 % over tp2 off at every size, noise-limited) and does not reach the pre-registered +15 % at 4k.
- Recommendation: leave tp2 `--spec off` as the HIP default; `--spec mtp` at tp2 is available opt-in for a single long-context stream, where it is worth about +7 % over tp2 off. If a single-stream HIP 35B is wanted, **tp1 MTP k2 on one card matches tp2 off at 1k to 4k (193 / 197 vs 191 / 189) and loses at 16k (160 vs 180)**, freeing the other card.
- Follow-up (not this lane): a captured speculative step at tp2 (`spec_step_ok`'s `tp.world == 1`), the lever that would move tp2 MTP towards its CUDA ratio.
