# DSpine-b16 draft for Qwen3.8-27B (lane dspine, 2026-11-07)

`--spec dflash --spec-draft <tencent/Qwen3.8-27B-DSpine-b16>`: a DFlash-style 16-row block draft (5 Qwen3 layers, hidden 5120, causal block,
8192-key window) with Tencent's per-layer code bridge and a greedy serial-table tail. Design: `docs/plans/2026-11-07-dspine-port.md`. Opt-in only:
no default changes. Default `--spec-k` for a DSpine draft is 3 (`spec::DSPINE_K_DEFAULT`).

* Checkpoint: `tencent/Qwen3.8-27B-DSpine-b16` (Apache-2.0), 4,051,831,880 B bf16; on tatooine at `/data/models/intarsia/Qwen3.8-27B-DSpine-b16`.
* Reference: `Tencent/DSpine` @ `6450af7` (Apache-2.0), `dspine_mlx/` read for semantics; fixture dumper `tools/dspine/dspine_mlx_fixture.py`.
* Not ported: dynamic verification (DSpark), the sampled (T>0) tail, tp>1 (refused), device top-k for the DSpine head (host candidates).

| Greedy ids vs `--spec off`, HIP (tatooine card 0, tp=1, fleetq #9090) | 10/10 identical: mtp2, DFlash2 k7, DSpine default / k3 / k7 on short and 4k, 512 tokens |
| DFlash / DFlash2 regression (`dflash_cpu`, `dflash2_cpu`) | 7 + 13 passed |

The design's rel-L2 target was 2e-3; 2e-2 was measured (bf16 pipelines with extra roundings). Real-weight model-level parity against MLX was not run;
the evidence for the real weights is the ids gates and the acceptance below.

## HIP speed (R9700, tp=1, Quark 27B MXFP4, `--mem-budget 29`, 512 forced greedy tokens, one run each, radiance down 23:01:14-23:04:30)

| prompt | off | MTP k2 | DFlash2 k7 | DSpine k3 (default) | DSpine k7 |
|---|---:|---:|---:|---:|---:|
| short (24 tok) tok/s | 35.96 | **60.33** | 49.08 | 48.72 | 41.61 |
| short tokens / pass | | 2.12 | 2.48 | 2.07 | 2.14 |
| 4k (4420 tok) tok/s | 35.07 | 69.06 | 63.80 | 67.95 | **73.49** |
| 4k tokens / pass | | 2.54 | 3.57 | 3.07 | 4.19 |

On 4k DSpine k7 is the fastest arm (+6 % over MTP k2, +15 % over DFlash2 k7). On the short prompt it accepts little and MTP k2 wins.
An earlier window (w2, 256 tokens, before the tables were built at load) had DSpine 4k k7 at 60.25 tok/s: the first pass carried the ~1 s table build.
k15 (the full block) was measured only in w2: 4.64 t/p at 4k but 40.7 tok/s, too costly at tp=1.
With a causal block a shorter block is a prefix of the longer one, so k7 and k15 give identical counts whenever no pass accepts more than 7 (w2 short: 130 passes / 124 accepted in both).

Metal (endor, loaded box, not a quiet comparison): DSpine k3 beats off; k7 does not; MTP k2 is ahead of both. See the lane's `scripts/dspine/ids.sh` runs.
