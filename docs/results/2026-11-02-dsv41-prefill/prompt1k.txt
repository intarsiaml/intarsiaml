# DeepSeek V4.1 Flash at TP=2: rank caches, runtime, engine (lane dsv41/tp2)

Lane `dsv41/tp2`, 2026-10-31 / 11-01. Mia EXL3 2.9 bpw checkpoint
(`Mia-AiLab/DeepSeek-V4.1-Flash-1017-EXL3-EAQ-v1-2.9-bpw` @ `45ee5d0f`), text only.

## What is in the branch

- **Per-rank weight cache** (`crates/intarsia-models/src/dsv41_cache.rs`, `intarsia dsv41-cache --model CKPT --out DIR --rank R
  --world W [--layers N]`): an already-sharded safetensors checkpoint per rank on the Spark's local NVMe, plus config,
  tokenizer, chat template and the Engram token map. Column-parallel EXL3 linears (`wq_b`, shared `w1`/`w3`, `head`) keep
  `N / W` outputs. Row-parallel ones (`wo_b`, shared `w2`) keep `K / W` inputs. `attn_sink` keeps `H / W` heads. `wo_a`
  keeps the rank's `o_groups / W` slices, renumbered from 0. Routed experts are stored as the built EXL3 `MoeExperts`
  arena (`I / W` wide). Indexer, compressor, router, hc and Engram `wkv` are replicated; `mtp.*` and `bias_vl` are
  dropped. The loader streams it with O_DIRECT (6.9 GB/s measured on spark2, 17.3 GiB few-layer cache), so the page
  cache never holds the weights.
  Caches built: spark1 `~/intarsia-dsv41-tp2/cache/r0of2` and spark2 `~/intarsia-dsv41-tp2/cache/r1of2`, 97 GB each.
  `l3-*` are few-layer (`--layers 3`) caches for parity.
- **TP graph** (`dsv41::graph::build_with(.., GraphTp { world, layers })`): heads, groups and experts per rank. The
  collectives are stage extras, not ops (the op set is frozen):
  - an f32 partial all-reduce after `wo_b` and after the MoE (`Comm::all_reduce_sum_into`, rounded once);
  - an all-reduce of the gathered Engram rows (a rank's foreign rows are exact zeros);
  - an all-gather of the head's logits.

  `layers` truncates the model for few-layer runs.
- **Fused routed + shared experts**: one `MoeExperts` launch per layer. The shared expert is expert 384 of a 385-row
  arena, picked by a 7th slot of weight 1. At decode a fill writes that slot; prefill uses transpose, fill, transpose
  (TensorFold's served-decode layout). `dsv41::runtime::fuse_shared_experts` appends it at load.
- **Runtime** (`intarsia_core::dsv41::runtime`): an eager executor over the graph for one rank and one sequence.
  - Engram: both layers' rows are hashed and issued as soon as a pass's token ids are known. The pass waits for layer
    *l*'s records right before layer *l*, an eager split of the pass at layers 1 and 14.
  - `touch` runs at pass start and before the logits read.
- **Engine** (`crates/intarsia-models/src/dsv41_engine.rs`): the single-sequence `Engine` for `generate` / `serve`, with
  prefix reuse down to the ring margin.
  - A rank cache passed as `--model` is detected by `load_engine_group`.
  - Rank 1 runs `intarsia tp-worker` with its own cache. `tp_remote::serve` is now generic over a `RankModel`
    (`Model` is unchanged). The handshake fingerprint is the source checkpoint plus world, layers, capacity, chunk and
    act.
