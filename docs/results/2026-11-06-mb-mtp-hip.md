# mb-MTP on the R9700: 27B tp1, sampled speculation (2026-11-06)

**Result: +11.3% decode (geomean over 7 categories) at temperature 1.0, every category up in both rounds.** mb-MTP
(`INTARSIA_SPEC_MB=1`, branch `spec-mb-mtp`) against plain sampled speculation (`INTARSIA_SPEC_SAMPLED=match`), both MTP
k=2. Opt-in, off by default: it changes the output law (see Limits).

## What mb-MTP is

Ported from llamAmpere v0.6 (`common/sampling.cpp`, `common_sampler_verify_pq`, "mode-biased MTP"). On a rejected draft
the replacement token is drawn as usual; if the target rates the draft at least as likely as that replacement,
`p(d) >= p(x)`, and neither is a stop or EOS token, the draft is kept and verification continues. Code:
`crates/intarsia-core/src/spec.rs` (`mb_from_env`, `accept_sampled`), stop set from `Seq::stop_ids` in `engine.rs`.

## Setup

- tatooine, one R9700 (card 0), Qwen3.8-27B Quark AWQ MXFP4, `serve --backend hip --spec mtp --spec-k 2 --max-batch 1`,
  binary built from `spec-mb-mtp` (fleetq #8878).
- Window `scripts/dt1/cat-window.sh`, W=mb2 (fleetq #8884, radiance down 22:31:30-22:58:19), `TEMP=1.0`, 512 forced
  tokens per request, 7 category files, 2 rounds with the arm order swapped (mb, match | match, mb).
- Arms: `mtp2-on` = `INTARSIA_SPEC_SAMPLED=match`; `mtp2-on3` = the same plus `INTARSIA_SPEC_MB=1`.
- Window mb1 (fleetq #8881, radiance down 21:33:57-21:51:37) is void for the mb arm: the localeval recipe string was
  over 255 characters and localeval `stat()`s it as a file name, so every mb request failed before reaching the server.
  Fixed in the window script (recipe shortened and length-checked). Its match arm agrees with mb2's within 2%.

## Limits

- **Lossy, not measured here.** mb-MTP is no longer exact in law: the output leans toward the target's likelier
  tokens. llamAmpere reports 0.009 KL per token at draft depth 6 on their model; this window measured speed only.
  Sampled outputs from both arms read as coherent text (one prose sample per arm checked by eye), nothing more.
- Only k=2, tp1, batch 1, temperature 1.0, 512-token outputs at short context. Not run: tp2, other temperatures,
  long context, CUDA, Metal.
- HIP sampled speculation itself is off by default (`SampledSpec::default_for`); both arms set it explicitly. Its 56%
  acceptance on chat is the first served HIP run of it at temperature > 0.
