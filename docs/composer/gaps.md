## How cells are judged

- Same setup only. A gap counts only against a rival on **IntarsiaML's own quant**; the cell's `same_quant_*` fields are relative to the winner's quant, so the margin is recomputed from `contenders[]`: `rival / IntarsiaML - 1`.
- Noise = max(floor, both spreads); floors: decode 5%, prefill 10% under 16k and 5% from 16k, concurrent 10% (`build_regimes.py:47`). Inside the noise the cell is a tie.
- Rank score = margin % x phase weight. Weights (a judgement, not a measurement): decode 1.0, prefill 1.0, concurrent 0.5. Concurrent is half-weight because aggregate decode over N streams repeats the decode lever and is noisier.
- An empty quant is unknown, never a match; those cells are listed apart.
